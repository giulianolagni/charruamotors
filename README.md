# charruamotors
Aplicativo Android em Kotlin para controle de manutenção veicular, gestão de abastecimentos e leitura de dados do motor em tempo real com scanner OBD2 via Bluetooth. Terá armazenamento de dados offline (Room) e as 4 telas exigidas: Login, Dashboard, CRUD de veículos e Histórico/Diagnóstico.
